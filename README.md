# 📺 koyeb-tv — محطة تلفزية على Koyeb بدون ffmpeg (nginx فقط)

محطة بث تلفزي حقيقية تعمل على مدار الساعة 24/7 بموارد خفيفة جداً، مبنية على **nginx فقط**:

| نوع القناة | المصدر | التقنية |
|---|---|---|
| **القناة الرئيسية** | ملفات **MP4 و MKV** في مجلد `media/` | بث حي وهمي (Fake-Live) عبر وحدة `nginx-vod-module` — إعادة تغليف HLS فورية **بدون أي ترميز أو ffmpeg** |
| **قنوات خارجية (حتى 8)** | روابط **m3u8** أو **TS** من أي مصدر | تمرير عبر `proxy_pass` مع إعادة كتابة الروابط تلقائياً |

**الرابط الناتج** يعمل في كل شيء: VLC، تطبيقات IPTV (TiviMate، OTT Navigator، IPTV Smarters)، المتصفح (صفحة مشغل مدمجة تدعم hls.js وmpegts.js)، ووسم `<video>` في Safari.

---

## 🎬 مصادر المحتوى المدعومة

| المصدر | أين يوضع | ملاحظات |
|---|---|---|
| **MP4** (H.264 + AAC) | مجلد `media/` | الصيغة المثالية — تعمل مباشرة |
| **MKV** (H.264 + AAC/AC3/MP3) | مجلد `media/` | تعمل مباشرة أيضاً — الوحدة تفك الماتروسكا وتعيد تغليفها TS |
| MP4/MKV بـ **H.265/HEVC** | ❌ | غير مدعوم في حزم TS — لا يمكن إعادة تغليفه بدون ffmpeg |
| MKV بصوت **DTS/Opus/TrueHD** | ❌ | يُستبعد الملف برسالة واضحة في السجل (المدعوم: AAC/AC3/MP3) |
| MKV بلا صوت | ✅ | مقبول (بث صامت) |
| **رابط m3u8** | متغير `RESTREAM_URL` … `RESTREAM_URL_8` | حتى 8 قنوات خارجية |
| **رابط .ts متواصل** | متغيرات القنوات نفسها (يُكتشف تلقائياً) | يُشغَّل في صفحة الويب عبر mpegts.js |
| **مغناطيس تورنت** | ❌ مباشرة | انظر القسم أدناه — البديل العملي: `MEDIA_URL` |

> 💡 للتحقق من ترميز ملفك بدون ffmpeg: افتحه في VLC ← أدوات ← معلومات الترميز وابحث عن `H264` و`MP4A` أو `A_AAC`.

---

## 🧲 بخصوص التورنت (magnet)

لا يمكن للمحطة سحب مغناطيس تورنت مباشرة، وذلك لثلاثة أسباب عملية:

1. **سياسة المنصة**: حركة P2P على Koyeb قد تُعرّض حسابك للإيقاف.
2. **بدون ffmpeg**: معظم التورنتات بصيغة HEVC/x265 — مستحيل إعادة تغليفها للبث الحي بهذه الوحدة.
3. **التخزين المؤقت**: الحاوية تفقد ملفاتها عند كل إعادة نشر، وتنزيل فيلم كامل عند كل إقلاع غير عملي.

**✅ البديل العملي — `MEDIA_URL`:**
1. نزّل الملف على جهازك وتأكد أنه **H.264 + AAC** (إن كان HEVC حوّله مرة واحدة ببرنامج مثل HandBrake).
2. ارفعه كـ **Release asset** على GitHub (أو أي رابط مباشر): أنشئ Release جديدة وأرفق الملف، ثم انسخ رابطه المباشر.
3. أضف متغير بيئة في Koyeb:
   ```
   MEDIA_URL = https://github.com/USERNAME/REPO/releases/download/v1/movie.mp4
   ```
   الحاوية تنزّله تلقائياً عند كل إقلاع (يدعم عدة روابط مفصولة بفواصل، والحد `MEDIA_MAX_MB` افتراضياً 2048MB).

أما ملفاتك الصغيرة (حتى 25MB) فارفعها مباشرة إلى مجلد `media/` في المستودع.

## 🧠 كيف تعمل بدون ffmpeg؟

وحدة `nginx-vod-module` تقرأ ملفات MP4/MKV مباشرةً من القرص وتعيد تغليفها إلى مقاطع HLS لحظة الطلب — **لا فك ترميز ولا إعادة ترميز**، استهلاك معالج شبه معدوم، مثالي للخطة المجانية على Koyeb (0.1 vCPU / 512MB RAM / 2GB SSD).

سكربت بايثون خفيف (مكتبة النظام فقط) يحلّل مدة كل فيديو مباشرة من ذرات MP4 أو من عناصر EBML في MKV، ثم يبني «جدول قناة» حلقي لا نهائي يُجدَّد كل 15 ثانية — نفس خوارزمية المثال المرجعي في وحدة vod نفسها (`test/playlist.php`).

```
المشاهد ──► https://app-name.koyeb.app/live/main/index.m3u8
                        │
                nginx + vod-module
                ├─ /map/live/main  ← جدول القناة (يتجدد كل 15 ث، حلقة 24/7)
                ├─ يقرأ media/*.mp4 و *.mkv ويعيد تغليفها إلى مقاطع .ts لحظياً
                └─ /restream/2..8  ← وكلاء القنوات الخارجية (m3u8/ts)
```

2. حساب GitHub (لرفع المشروع والوسائط الكبيرة) — أو Docker Hub إن فضّلت الصورة الجاهزة.

## 🚀 النشر عبر GitHub (الأسهل — هو المستخدم حالياً)

### 1) ارفع المشروع إلى مستودع

ارفع كل محتويات المجلد إلى مستودعك بحيث يبدو هكذا:

```
repo/
├── Dockerfile
├── .dockerignore
├── nginx/nginx.conf.template
├── scripts/  (5 ملفات)
├── www/index.html
└── media/    ⬅️ ملفات MP4/MKV هنا (اختياري — أو استخدم MEDIA_URL)
```

> ⚠️ عند الرفع من واجهة GitHub تُفقد صلاحية التنفيذ — لا مشكلة: الـ Dockerfile يصلحها تلقائياً (`chmod +x`) ويشغّل السكربت عبر bash مباشرة.

### 2) أنشئ الخدمة على Koyeb

1. [app.koyeb.com](https://app.koyeb.com) ← **Create Service** ← **GitHub** واختر المستودع.
2. **Instance**: `Free`.
3. **Exposure / Port**: `8000` ببروتوكول `HTTP`.
4. **Health check**: اختر HTTP بالمسار `/healthz`.
5. **Environment variables**: أضف متغيرات القنوات الخارجية و`MEDIA_URL` إن أردت (الجدول أدناه).
6. **Deploy** — أول بناء يستغرق ~5 دقائق (تجميع nginx)، وما بعده ثوانٍ من الكاش.

### 3) (بديل) النشر عبر Docker Hub

```bash
docker build -t USERNAME/koyeb-tv:latest .
docker push USERNAME/koyeb-tv:latest
# ثم في Koyeb اختر Docker image: docker.io/USERNAME/koyeb-tv:latest
```

### 4) شاهد قناتك 🎉

| ماذا تريد | الرابط |
|---|---|
| صفحة المشغل (من المتصفح) | `https://APP.koyeb.app/` |
| قناة ملفاتك (لأي مشغل IPTV / VLC) | `https://APP.koyeb.app/live/main/master.m3u8` |
| القناة الخارجية رقم 2 | `https://APP.koyeb.app/restream/2/…` (الرابط الكامل يظهر في صفحة المشغل) |
| فحص الصحة | `https://APP.koyeb.app/healthz` |

**في VLC**: وسائط ← فتح بث شبكي ← الصق رابط `master.m3u8`.

## ⚙️ متغيرات البيئة (كلها اختيارية)

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `PORT` | `8000` | منفذ nginx — طابِقه مع منفذ الخدمة في Koyeb |
| `CHANNEL_NAME` | `قناتي HD` | اسم القناة الرئيسية في صفحة المشغل |
| `SEGMENT_DURATION` | `10000` | مدة مقطع HLS بالمللي ثانية |
| `LIVE_WINDOW` | `60000` | طول نافذة قائمة البث بالمللي ثانية |
| `SCHEDULE_INTERVAL` | `15` | كل كم ثانية يُعاد توليد جدول القناة |
| `SCHEDULE_EPOCH_MS` | `1767225600000` | بداية الخط الزمني (2026-01-01) — ثباتها يحفظ استمرارية البث بعد إعادة النشر |
| `MEDIA_URL` | *(فارغ)* | روابط مباشرة لملفات mp4/mkv تُنزَّل عند الإقلاع (مفصولة بفواصل) |
| `MEDIA_MAX_MB` | `2048` | الحد الأقصى لحجم ملف واحد يُنزَّل عبر MEDIA_URL |
| `RESTREAM_URL` | *(فارغ)* | القناة الخارجية 1: رابط m3u8 أو .ts |
| `RESTREAM_NAME` | `قناة خارجية 1` | اسمها في المشغل |
| `RESTREAM_TYPE` | `auto` | `auto` / `hls` / `ts` |
| `RESTREAM_URL_2` … `RESTREAM_URL_8` | *(فارغ)* | قنوات خارجية إضافية (بنفس نمط الاسم والنوع: `RESTREAM_NAME_2`، `RESTREAM_TYPE_2`…) |

## 🔄 تحديث المحتوى أو الإعدادات

- **تغيير متغيرات البيئة** (قنوات خارجية، MEDIA_URL): من Koyeb ← الخدمة ← Settings ← Environment — ثم **Redeploy**. لا حاجة لإعادة بناء الصورة.
- **تغيير ملفات media/**: ارفع/احذف من GitHub ثم **Redeploy** (بناء سريع بالكاش).

التسلسل الزمني للبث لا ينكسر عند أي إعادة نشر لأنه محسوب من `SCHEDULE_EPOCH_MS` الثابت.

## 🩹 استكشاف الأخطاء

| المشكلة | السبب والحل |
|---|---|
| الحاوية تفشل بـ `exited with code 13` | كانت صلاحية تنفيذ entrypoint مفقودة بسبب رفع واجهة GitHub — **مُصلَّحة تلقائياً في Dockerfile الحالي** (`chmod +x` + تشغيل عبر bash)؛ حدّث نسختك إن كنت تستخدم نسخة أقدم |
| «القناة غير متاحة» في الصفحة | لا ملفات صالحة في `media/` — راجع رسائل `[schedule]` في السجل: ستقول لك كل ملف مستبعد وسببه (HEVC؟ صوت DTS؟) |
| المقاطع تُحمّل ثم يتوقف البث | ملف تالف — راجع سجل الحاوية (Runtime Logs) |
| قناة خارجية 403/404 | المصدر يحجب إعادة البث أو الرابط انتهت صلاحيته — جرّب رابطاً آخر |
| قناة TS لا تعمل في المتصفح | تأكد أنك تفتح صفحة المشغل نفسها (تستخدم mpegts.js تلقائياً)، أو استخدم رابط القناة في تطبيق IPTV |
| بطء أول تشغيل | طبيعي — المشغل يبدأ بعد 3 مقاطع |
| الخدمة «نائمة» | الخطة المجانية قد تخمّد الخدمات — أداة مراقبة خارجية (UptimeRobot) ترسل ping كل 5 دقائق تُبقيها مستيقظة |

## 📁 بنية المشروع

```
koyeb-tv/
├── Dockerfile                    # nginx 1.28 + vod-module مع تفعيل MKV (مرحلتان)
├── docker-compose.yml            # تشغيل محلي للتجربة
├── nginx/
│   └── nginx.conf.template       # إعدادات المحطة (متغيراتها تُستبدل عند الإقلاع)
├── scripts/
│   ├── entrypoint.sh             # تهيئة وإقلاع كل شيء
│   ├── build_schedule.py         # مولّد جدول القناة الحلقي 24/7 (بدون ffmpeg)
│   ├── mp4_info.py               # قارئ مدة/ترميز MP4 و MKV (محلل EBML مدمج)
│   ├── restream_env.py           # محلل روابط القنوات الخارجية (مكتبة)
│   ├── gen_restream.py           # مولّد مواقع nginx للقنوات 1..8
│   └── media_fetch.py            # منزّل MEDIA_URL عند الإقلاع
├── www/
│   └── index.html                # صفحة المشغل (hls.js + mpegts.js، عربية RTL)
└── media/                        # ⬅️ ملفات MP4/MKV هنا
```

## 🔐 ملاحظة أمنية

مسار `/map/` الداخلي (جداول البث) محمي بـ `internal` ولا يمكن فتحه من الخارج. جميع نقاط البث تعمل بلا مصادقة — إن أردت حماية قناتك أضف لاحقاً وحدة `secure_link` أو قاعدة `geo/allowlist` في nginx.conf.
